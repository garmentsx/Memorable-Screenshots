
# Memorable Screenshots 📷
Uses your in-game screenshots as your game's hero like in the old days of steam (kinda)

> [!IMPORTANT]  
> This plugin is meant to be used with the Classic Library Theme Or Number's upcoming "Legacy Steam" Theme, it won't look good without it!




## Prerequisites


[Millennium](https://steambrew.app/)

[Classic Steam Library](https://steambrew.app/theme/r2XyxiKzVyAIqsO3VIRF)
